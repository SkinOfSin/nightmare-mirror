# Skin of Sin — Nightmare Mirror

Interactive body-horror kaleidoscope by [@ANancysilver](https://x.com/ANancysilver).

Paint mirrored wounds. Spiders crawl out. Blood splatters. Ritual overlays. Export stills and record clips.

## Live app

**https://nightmaremirror.grok.me**

## Open locally

Open `index.html` in any browser (full standalone app — no build step).

## Source layout

| Path | What it is |
|------|------------|
| `index.html` | Full standalone app (use this for GitHub Pages) |
| `public/nightmare.html` | Same standalone file |
| `src/components/` | React canvas + controls (Build Mode source) |
| `src/lib/` | Audio, color modes, utils |
| `src/routes/` | App routes |
